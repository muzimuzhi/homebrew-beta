# Homebrew tap `muzimuzhi/beta`

## Quick actions

```bash
# installation
brew install muzimuzhi/beta/NAME

# formula upgrading
brew bump-formula-pr muzimuzhi/beta/FORMULA --version=VERSION [--write-only]

# cask upgrading
brew bump-cask-pr muzimuzhi/beta/CASK --version=VERSION [--write-only]

# check out latest template workflows
brew tap-new --github-packages --no-git USER/REPO
```

Changes to the template workflows generated by `brew tap-new`:
- `tests.yml`: also run on a Intel macOS runner, the Arch I'm on
- `autobump.yml`: added `on.workflow_dispatch` trigger, added `autobump-casks` job which runs on macOS

## History

On 29 Jun 2020, This repository was initially created to provide `texstudio-beta` (2.12.22beta2) cask which was [removed][texstudio-beta removed] on 5 May 2025 from [`Homebrew/cask-version`][Homebrew/cask-version] tap due to too few downloads. (The [`Homebrew/cask-version`][Homebrew/cask-version] repo was archived in [Homebrew 4.3.0][homebrew-4.3.0] in May 2024, and deleted in someday later.)

On 14 Sept 2025, the [`texstudio` cask][texstudio core cask] in `Homebrew/cask` core tap was marked deprecated and to be disabled on 2026-09-01 in [`Homebrew/homebrew-cask@dc74ecc`][Homebrew/homebrew-cask@dc74ecc] (texstudio 4.8.9, 2025-09-14)

> _(info shown when working with `texstudio` core cask since its deprecation)_\
> Deprecated because it does not pass the macOS Gatekeeper check! It will be disabled on 2026-09-01.

On 19 Aug 2026, a new [`texstudio-org/texstudio`][texstudio-org/texstudio] tap is set-up and all `texstudio`-related casks were moved there.
